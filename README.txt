FARHANA & SHAFEEQ — ROYAL NIKKAH INVITATION

Files:
- index.html: website content
- styles.css: burgundy, ivory and gold design and scroll animations
- script.js: reveal-on-scroll, petals, music controls and countdown
- assets/couple-illustration.jpg: supplied couple illustration (black footer trimmed)
- assets/wedding-nasheed.mp3: supplied audio file

To preview locally, open index.html in a browser. For deployment, upload all files and folders to the root of the existing GitHub repository connected to Vercel. Vercel will redeploy automatically after the commit.

Note: Music starts after the visitor taps OPEN THE INVITATION because browsers block autoplay before a user gesture.
